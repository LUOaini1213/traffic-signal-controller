# Robustness review — 2026-10-03

Reviewed base: `85aea6d65bcec08e518831a4fc9da56486e2ebb8`.
The base was freshly built under Ubuntu 24.04 / GCC 13, and all 94 existing tests passed
before the regression tests below were added.

## Reproduced problems and changes

### Replay silently lost Windows CSV arrivals

Given `5,N_2,1` followed by `5.5,N_2,0`, replaying to 30 s served the right-turn phase once
with LF line endings. The same CRLF file served it zero times, while both runs exited zero
and reported no audit violations. The last field retained `\r`, so `on == "1"` was false.

The CLI now accepts LF/CRLF, optional UTF-8 BOM, field padding and blank data lines. It
requires the documented header, exactly three fields, a known detector and a `0`/`1` event.
Both event and horizon times must be finite, non-negative, fully parsed seconds within
the millisecond clock range. Invalid files fail with line context before any replay output.
The final tick uses a bounded increment to avoid integer overflow near the clock limit.

Eleven Python unittest groups launch the real compiled CLI. They compare signal timelines
and summaries across file formats, check an OFF-only event, and reject malformed input.
Against the old executable the suite failed; all eleven pass after the fix. CMake runs this
suite alongside GoogleTest in each test build, including sanitizer builds.

### An existing stuck-off fault masked a later feed disconnection

With only N_1/S_1 reporting traffic, six neighbouring loops become stuck-off at 900 s.
Disconnecting all eight N/S loops at 900.5 s previously counted only two lost feeds: the
other six already had a fault, so `force_fault` returned early. The junction stayed out of
fail-safe even though the configured limit was four lost/stuck-on loops.

A FeedLost declaration now supersedes either occupancy fault. The fault remains latched;
each detector counts once, duplicate notifications and downgrades are ignored, and the
history retains both the initial fault and the later disconnection time.

The regressions cover monitor state, the exact fail-safe threshold, and real producer
`emit/advance/close` calls through ControllerRuntime. In two message interleavings, all
1,809 ticks through 904 s are checked: fail-safe starts at 900.5 s, all signals are red by
904 s, and E/W are not falsely declared disconnected. The history contains six stuck-off
declarations at 900 s and eight feed-loss declarations at 900.5 s.

### Backwards timestamps could shorten fail-safe yellow

After NS green was last observed at 20 s, an invalid command timestamp of 1 s correctly
triggered fail-safe, but incorrectly backdated yellow to 1 s. At the next valid 20.5 s
call the guard already showed red, despite a required 3 s yellow. Explicit fail-safe
requests had the same weakness.

The guard now uses the latest observed time (never before its start time) for fail-safe
timing in both entry points. It still rejects repeated/backwards commands, preserves the
start of a yellow already displayed, and supports a request followed by `apply` at the same
tick. Five of the new test cases failed on old code; all eight added test cases pass with
the fix. Normal controller ticks were already monotonic; this closes the public guard's
abnormal-input recovery path.

## Validation

- GCC Debug and Release: 105 GoogleTest cases plus the 11 CLI groups; CTest **106/106**.
- SUMO 1.18 smoke: fixed, actuated, SUMO skip, SUMO no-skip, and injected stuck-loop cases;
  all five passed, with traffic completing and zero reported safety violations.
- Additional required gates: clang-tidy, ASan/UBSan, TSan with its SUMO harness, and all
  66 mutation cases. See the PR's final checks for their current outcomes.

Fault-history tests assert that records exist before indexing them. A missing declaration
therefore produces an ordinary assertion failure, rather than a test-side out-of-bounds
crash. Mutation checks reject failed builds and abnormal test exits without a failure
report, and restore the original source bytes after each case.

The README's historical 280-run evaluation tables and calibration are unchanged. This
review reruns short simulation checks, not the full 280-run study. The project remains a
simulation controller, not a field-certified or deployed traffic-signal system.
